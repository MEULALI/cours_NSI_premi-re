Chapitre n°1 : constructions de base pour programmer en Python

Spe NSI

✻ Introduction

Dans ce chapitre, on présente les constructions qui constituent le noyau du langage de programmation Python :

  • les littéraux, les types de base (int, float, bool) ;
  • la notion de variable, l’instruction d’affectation et la distinction entre expression et instruction ;
  • les instructions constituant les briques de base d’un langage de programmation :
    • la boucle bornée for ;
    • les instructions de branchement if ... elif ... else ;
    • la boucle non bornée while ;
  • les fonctions, qui permettent de réutiliser et rendre plus lisible le code.

1. Bases d’un langage de programmation : instructions, littéraux, expressions

1.1 Langage de programmation et instruction

Définition 1

Un langage de programmation permet d’écrire des programmes exécutés par un ordinateur.
Python est un langage interprété créé par Guido Van Rossum dans les années 1980.
Le code Python peut être évalué directement par un interpréteur (sans compilation en langage machine), en mode interactif (console) ou en mode programme (fichier .py).

Exemple en mode interactif :

>>> 1 + 2
3
>>> "1" + "2"
'12'
>>> "1" + 2
TypeError: can only concatenate str (not "int") to str

Exécution d’un script :

bash

Copier

user@pc-$ python hello_world.py
Hello world

1.3 Littéraux et types de base

Définition 3

Un littéral est un texte interprété par Python pour créer un objet en mémoire avec une valeur spécifiée.
Un objet Python est caractérisé par :

  • son identité (fonction id()) ;
  • son type (fonction type()) ;
  • sa valeur.

Exemple :

python

Copier

>>> id(842)
140200201318000
>>> type(842)
<class 'int'>

Types de base

Type Domaine de valeurs Opérateurs Exemple de littéraux
int entiers signés + - * // % ** 0 -4 842
float sous-ensemble des décimaux + - * / ** 0.0 -1.0 3.14
bool valeurs logiques not and or True False
str chaînes de caractères + ‘tb’ " ‘2.4’ ‘Bonjour’

⚠️ Priorité des opérateurs :

  • L’exponentiation (**) a la priorité la plus élevée.
  • Utilisez des parenthèses pour clarifier ou contourner les règles de priorité.

Exemple 1 : Opérations sur les types de base

python

Copier

>>> 11 + 3       # Addition → 14
>>> 11 * 3       # Multiplication → 33
>>> 11 ** 3      # Exponentiation → 1331
>>> 11 // 3      # Quotient euclidien → 3
>>> 11 % 3       # Reste euclidien → 2
>>> 11 / 3       # Division décimale → 3.666...
>>> not True     # Négation booléenne → False
>>> True or False # Disjonction → True
>>> '2' + '1'    # Concaténation → '21'
>>> '2' + 1      # Erreur : TypeError

1.4 Variable et expression

Définition 4

Une variable est l’association entre un nom et un objet Python (sa valeur).
L’opérateur = réalise cette association (affectation).

Exemple :

python

Copier

x = 842  # Affectation
y = x + 1  # y = 843

Définition 5

Une expression est une combinaison de littéraux et de variables dont la valeur peut être évaluée.
Exemple : Si x = 842, alors x + 1 vaut 843.

Remarque 1

  • Règles syntaxiques pour les noms de variables :

    • Ne pas commencer par un chiffre.
    • Pas de tiret haut (-).
    • Utiliser des minuscules et des tirets bas (compteur_vie).
    • Voir : PEP 8 (conventions de style).

  • Effet de bord : x = x + 1 incrémente x (si x est défini).

    ⚠️ = n’est pas un opérateur d’égalité (utiliser == pour comparaisons).

Méthode : Tableau d’état

Pour comprendre un programme, on peut tracer les valeurs des variables à chaque étape.

Exemple : Échange de valeurs entre a et b

Solutions :

  1. Avec une variable temporaire :

    python

    Copier

    a = 842
b = 843
c = a
a = b
b = c

  1. Avec déballage de tuple (plus “pythonique”) :

    python

    Copier

Comparaison de variables

  • == : Compare les valeurs.
  • is : Compare les références (même objet en mémoire).

python

Copier

>>> a = 842
>>> b = 843
>>> a == b
False
>>> a = a + 1

>>> c = a
>>> c is a
True   # Même référence

2. Instructions conditionnelles (ou de branchement)

Exemple 2 : Solde bancaire

python

Copier

recette = float(input('Recette ?'))
debit = float(input('Débit ?'))
solde = recette - debit

if solde < 0:
    agios = solde * 0.1
    solde = solde + agios

if solde < 0:
    print("Solde débiteur :", solde, "dont agios :", agios)

Exemple : Tarif d’entrée au musée

python

Copier

age = int(input('Âge ?'))
if age < 6:
    tarif = 0
elif age < 13:
    tarif = 5
else:
    tarif = 10

Définition 6

Syntax générale :

python

Copier

if condition1:
    # Bloc 1
elif condition2:
    # Bloc 2
else:
    # Bloc par défaut

  • Seul le premier bloc dont la condition est True est exécuté.

  • Opérateurs de comparaison :
    ==, !=, >, <, >=, <=

  • Opérateurs logiques :
    and, or, not

  • Précédence : not > and > or.

    💡 Utilisez des parenthèses pour clarifier !

Exemple :

python

Copier

>>> 3 < 4 and 5 == 2*2 + 1  # True
>>> (3 < 4) and (5 == 2*2 + 1)  # Plus lisible

Remarque 2 : Validation de données

python

Copier

age = -10
assert (age >= 0 and age <= 120), "valeur invalide"  # Interrompt le programme si False

Équivalent à :

python

Copier

if not (age >= 0 and age <= 120):
    exit("valeur invalide")

3. Boucle bornée

Définition 7 : Boucle for

Utilisée pour répéter un bloc d’instructions un nombre connu d’itérations.

Programme 2 : Répéter une action

Copier

for k in range(4):
    print("bonjour")

Sortie :

Programme 3 : Parcourir une plage

python

Copier

for k in range(4):
    print(k)

Sortie :

text

Copier

Syntax générale

python

Copier

for element in iterable:
    # Bloc d'instructions
  • range(n) : Itère de 0 à n-1.
  • range(m, n) : Itère de m à n-1.
  • range(m, n, s) : Itère de m à n-1 avec un pas s.

Exemple avec chaînes et listes :

python

Copier

# Parcourir une chaîne
for c in 'AB':
    print(c)  # A, B

# Parcourir une liste
for x in [2, 6]:
    print(x**2)  # 4, 36

Remarque 3 : Indentation

  • En Python, l’indentation est un élément de syntaxe (pas seulement de présentation).
  • Une IndentationError se produit si le bloc n’est pas indenté.

Exemple de boucles imbriquées :

python

Copier

# Tous les couples (i, j) avec 1 ≤ i ≤ 3 et 1 ≤ j ≤ 3
for i in range(1, 4):
    for j in range(1, 4):
        print(i, j)

4. Boucle non bornée

Définition 8 : Boucle while

Utilisée quand le nombre d’itérations n’est pas connu à l’avance.

Syntax :

python

Copier

while condition:
    # Bloc d'instructions
  • La condition doit être une expression booléenne.
  • La boucle s’arrête quand la condition devient False.

⚠️ Attention : Assurez-vous que la condition finira par être False, sinon boucle infinie !

Exemple 3 : PGCD (méthode d’Euclide)

python

Copier

a = int(input('Entier a ?'))
b = int(input('Entier b ?'))
while b != 0:
    tmp = a
    a = b
    b = tmp % b  # Reste de la division euclidienne
print("PGCD :", a)

Exemple : Doublement d’une population

python

Copier

population = int(input("Population initiale ? "))
double = 2 * population
n = 0
taux = 2 / 100  # 2% par an
while population < double:
    population = population * (1 + taux)
    n = n + 1
print("Doublement en", n, "années")

Méthode

  • Boucle infinie volontaire (ex: chronomètre) :

    python

    Copier

    import time
compteur = 1
while True:
    print(compteur)
    compteur += 1
    time.sleep(1)  # Attend 1 seconde

  • Boucle infinie involontaire (ex: compte à rebours avec start non défini) :

    python

    Copier

    while compteur >= 0:
    print(compteur)
    compteur -= 1
    time.sleep(1)

5. Fonctions

5.1 Définir une fonction

Définition 9

Une fonction permet :

  • De réutiliser un bloc d’instructions.
  • De clarifier le code.
  • De factoriser la logique (modularité).

Syntax :

python

Copier

def nom_fonction(param1, param2):  # Signature
    # Bloc d'instructions (corps)
    return valeur  # Optionnel
  • Avec return : Renvoie une valeur.
  • Sans return : Procédure (modifie l’état par effet de bord, renvoie None).

Exemple : Fonction carre

python

Copier

def carre(x):
    return x ** 2

Exemple : Fonction avec plusieurs paramètres

python

Copier

def carre_distance_origine(x, y):
    return x ** 2 + y ** 2

Exemple : Fonction retournant un tuple

python

Copier

def coord_vecteur(xA, yA, xB, yB):
    return (xB - xA, yB - yA)

Exemple : Procédure (sans return)

python

Copier

def message_defaite():
    print("Vous avez perdu, merci d'avoir participé")

⚠️ Attention : print(valeur) affiche la valeur, mais ne la renvoie pas !

python

Copier

def cube(x):
    print(x ** 3)  # Mauvaise pratique : ne renvoie rien (None)

b = cube(5)  # Affiche 125, mais b = None
print(b + 1)  # TypeError: unsupported operand type(s) for +: 'NoneType' and 'int'

5.2 Utiliser des bibliothèques de fonctions

Méthode

Pour utiliser des fonctions non chargées par défaut, importez-les depuis un module.

Exemple : Module math

python

Copier

# Méthode 1 : Importer le module
import math
racine = math.sqrt(2)  # Utilisation : module.fonction

# Méthode 2 : Importer une fonction spécifique
from math import sqrt
racine = sqrt(2)  # Utilisation directe

# Méthode 3 : Importer toutes les fonctions (déconseillé)
from math import *

Documentation :

  • En ligne : docs.python.org/3
  • Localement : python3 -m pydoc -b (lance un serveur web local).

Module random

Fonction Spécification
random.randrange(a,b) Renvoie un entier aléatoire dans [a; b[
random.randint(a,b) Renvoie un entier aléatoire dans [a; b]
random.random() Renvoie un décimal aléatoire dans [0; 1[
random.uniform(a,b) Renvoie un décimal aléatoire dans [a; b]

Module turtle

Permet de dessiner des figures géométriques avec une “tortue”.

Fonction Description
turtle.goto(x, y) Déplace la tortue jusqu’au point de coordonnées (x, y).
turtle.penup() Lève le crayon (pas de trace lors du déplacement).
turtle.pendown() Baisse le crayon (la tortue laisse une trace).
turtle.setheading(angle) Choisit l’angle d’orientation de la tortue en degrés.
turtle.forward(n) Avance de n pixels selon l’orientation actuelle.
turtle.left(a) Tourne à gauche de a degrés.
turtle.right(a) Tourne à droite de a degrés.
turtle.color("red") Change la couleur du crayon (ex: "red", "blue", "green").

Exemple 4 : Spirale avec turtle

python

Copier

import turtle as tt

def spirale(n):
    tt.penup()
    tt.goto(0, 0)
    tt.pendown()
    c = 5
    for i in range(4):
        for j in range(4):
            tt.forward(c)
            c = 10 + c
            tt.left(90)

spirale(4)
tt.exitonclick()  # Ferme la fenêtre au clic

6. Erreurs

Définition 10

On distingue plusieurs types d’erreurs (bugs) :

Type d’erreur

Cause

Exemple

SyntaxError

Syntaxe Python non respectée

4 = a → SyntaxError: cannot assign to literal

NameError

Variable non définie

3 * a + 1 → NameError: name 'a' is not defined

TypeError

Opération sur types incompatibles

2 + '2' → TypeError: unsupported operand type(s)

ZeroDivisionError

Division par zéro

8 / 0 → ZeroDivisionError: division by zero

KeyboardInterrupt

Interruption par l’utilisateur (Ctrl+C)

Boucle infinie → KeyboardInterrupt

Logique

Programme ne produit pas le résultat attendu

Boucle infinie non détectée

Débogage :

  • Lire les messages d’erreur de l’interpréteur.
  • Utiliser des print pour tracer les valeurs.
  • Utiliser un débogueur (points d’arrêt, outils de l’IDE).
