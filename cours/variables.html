1. Variables en Python

Une variable est un espace mémoire qui stocke une valeur.

Déclaration d'une variable

En Python, on déclare une variable avec le symbole =.

age = 18
nom = "Alice"
note = 15.5

Types de variables

  • Entier (int) : 42
  • Flottant (float) : 3.14
  • Chaîne de caractères (str) : "Bonjour"
  • Booléen (bool) : True ou False

Exercices

  1. Créez une variable prix avec la valeur 19.99 et affichez-la.
  2. Créez deux variables a et b avec les valeurs 5 et 10, puis affichez leur somme.
Voir les solutions 
# Exercice 1
prix = 19.99
print(prix)

# Exercice 2
a = 5
b = 10
print(a + b)
